# Arduino LED Blinking - QA Documentation

## Project Overview

This project implements a basic LED blinking system using an Arduino Uno.
The project demonstrates the use of GitHub for code management, QA issue
tracking, documentation, and problem solving.

## Objective

To implement an LED blinking system and use GitHub Issues to identify,
document, track, and resolve project-related problems.

## Hardware Requirements

- Arduino Uno
- LED
- 220Ω resistor
- Breadboard
- Jumper wires
- USB cable

## Software Requirements

- Arduino IDE
- GitHub

## Working Principle

The Arduino configures digital pin 13 as an output. The LED is switched ON
for one second and then switched OFF for one second. This process repeats
continuously.

## Expected Result

The LED should blink continuously with:

- ON time: 1 second
- OFF time: 1 second

## Quality Assurance

GitHub Issues are used to document project problems, identify their root
causes, propose solutions, and track their resolution.

The project will document multiple QA issues and their solutions using
GitHub Issues, comments, commits, and issue resolution.

## Learning Outcome

This project demonstrates how GitHub can improve transparency,
traceability, documentation, collaboration, and problem solving in an
embedded-system project.
